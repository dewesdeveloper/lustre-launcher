Lustre Public 0.1.21

- Лаунчер распознаёт установщик репака по содержимому файла, а не только по имени: раздачи вроде Rust (установщик с «игровым» именем и частями .bin) больше не принимаются за готовую игру
- Если игра уже «установилась» как установщик, лаунчер сам это исправит: на странице игры появится кнопка «Установить» — заново скачивать не нужно

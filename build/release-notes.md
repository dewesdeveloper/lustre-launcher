Lustre Public 0.1.5

- Обновления лаунчера теперь скачиваются с сервера Lustre — в разы быстрее, чем с GitHub. Если наш сервер недоступен, лаунчер сам возьмёт обновление с GitHub
- Проверка на вирусы: после скачивания Защитник Windows проверяет игру перед установкой. Если найдена угроза, установка останавливается, и вы сами решаете, продолжать ли
- Кнопка «Проверить на вирусы» на странице игры показывает, что нашёл Защитник у игроков, которые уже скачали эту игру. Сами файлы никуда не отправляются — только итог проверки

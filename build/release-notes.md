Lustre Public 0.1.20

- Ники и аватары пользователей в сообществах, поддержке, голосовом чате, комментариях и отзывах кликабельны — по клику открывается профиль
- В профиле появилась ссылка на библиотеку: своя открывает библиотеку лаунчера, чужая — игры пользователя
- Установка репаков меньше нагружает компьютер: установщик и его распаковщики работают с пониженным приоритетом, а несколько игр устанавливаются по очереди, а не одновременно
- Распаковка архивов использует меньше памяти
